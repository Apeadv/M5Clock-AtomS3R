# M5Clock v1.1.0

Bilingual release: the setup portal and the AtomS3R screen now support Chinese and English.

## Highlights

- 中文 / English switch on the setup page; the AtomS3R screen switches immediately.
- English screen layout: `WORLD TIME`, English city names and status messages.
- One blank column between digits on the three Chain Mono modules.
- Removed the moving seconds dot from the bottom row.
- M5Burner 8MB factory image included.

## Flash

- File: `M5Clock-AtomS3R-M5Burner.bin`
- SHA-256: `ee5f3681ff4ce7f3d7aef66b8e9c44ec8e1028ca4542114565e0aebf16fa6d3c`
- Address: `0x0`
- Flash size: `8MB`

Hold the AtomS3R button until the internal green LED turns on, then release, and burn with M5Burner.

## Notes

- Wi-Fi is configured on first boot via `M5-Clock-XXXX` / `http://192.168.4.1`.
- 2.4GHz Wi-Fi only.
- Hardware: AtomS3R + Atomic toChain Base + 3× Chain Mono (U217).
